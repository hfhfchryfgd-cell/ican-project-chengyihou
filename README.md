# 桥梁智巡

面向桥梁表观病害的桌面端巡检分析系统。本项目为可运行的 Python / PyQt6 源码交付，支持影像导入、批量目标检测、裂缝分割量化、任务归档、检测历史导出及长周期 AI 对比分析。

## 运行环境

- Windows 10/11
- Python 3.10 或更高版本（建议 3.10–3.12）
- 建议具备 NVIDIA GPU；未配置 GPU 时可使用 CPU 运行，速度较慢

## 快速启动

在项目根目录打开终端后执行：

```powershell
py -m pip install -r requirements.txt
py main.py
```

也可直接双击 `run.bat` 启动。首次运行只会自动创建 `data/` 下的数据库、影像库和结果目录，**不会生成任何演示任务、影像或检测记录**。

默认账号：`admin / 123456`。

## 模型权重说明

本仓库不包含任何模型权重文件，包括本项目自主训练或内部使用的权重，以及第三方模型权重。

`models/` 目录仅用于用户在本地放置已获得合法使用授权的模型文件。若需启用真实推理功能，请使用者自行从模型原始发布渠道获取相应权重，并遵守其许可证、署名要求及用途限制；本仓库不提供、转发或二次分发任何第三方权重。

未配置权重时，系统仍可使用内置演示流程展示界面与业务逻辑，并会显示明确状态提示；演示结果不代表真实模型性能。正式检测与分割请在本地合法配置权重后，安装 `torch`、`ultralytics` 等所需依赖再使用。

## 使用流程

1. 在“任务工作台”导入 `示例影像/` 中的图片或自己的桥梁病害影像并下达任务；
2. 系统依次完成检测、裂缝分割量化、任务归档与报告生成；
3. 在“检测历史”按时间查看真实任务，并导出某次任务的完整资料文件夹；
4. 在“长周期监测”选择两次历史任务，点击“AI智能分析”生成对比结论及 CSV、HTML、图片资料。

长周期 AI 分析需要在“系统设置”中启用并配置可用的大模型 API（兼容 DeepSeek 等 OpenAI 风格接口）。未连接 AI 时，界面会明确标记为“离线数据分析（AI 未连接）”，不会将离线差异计算伪装成 AI 结论。

## 目录说明

```text
bridge_inspect/    桌面端界面、算法、智能体与数据处理源码
models/            本地模型权重目录（仓库不包含权重文件）
main.py            程序入口
run.bat            Windows 一键启动脚本
requirements.txt   Python 依赖清单
data/              运行时自动创建的数据目录（不纳入源码提交）
示例影像/          可手动导入的原始裂缝样图，不写入运行数据库
```
